Upload your generated images to this `src/assets/images/` directory.

The images here will automatically be included in your builds and zipped into the browser extensions.

[Main Logo](logo.png) - Used in the README, GitHub repo, and extension store listings.
[Icon with Dark background](icon-dark-bg.png) - Used for browser extension icons to ensure visibility on dark mode.
[Icon with Transparent background](icon-transparent.png) - Used in places where the background is controlled, like GitHub Pages and documentation.
[Social Preview](social%20preview.png) - Used for link previews on social media and GitHub.

When adding new images, ensure they are optimized for web (compressed without losing quality) and named descriptively for their purpose.
