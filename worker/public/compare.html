Compare ledgers

Every CodeLedger repository publishes a small badges/stats.json alongside its badges. This page reads those files straight from GitHub and lines them up. Nothing is stored here, there is no account, and you do not need the extension installed to use it.

Worth knowing

  • The numbers are self-reported. Each file is written by the extension running on that person's machine, into a repository they control. Anyone can edit their own.
  • Only public repositories work. A repository that is private, renamed, or not publishing badges reads the same from here: not found.
  • Nobody is notified. Reading a public file leaves no trace the owner can see. This is a comparison, not a request to be compared.
