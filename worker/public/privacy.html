Privacy Policy

Last updated: June 2026

TL;DR — CodeLedger never sees your code, your AI keys, or your GitHub token. Everything lives in your browser and your own GitHub repo.

1. What data we collect

We collect nothing. CodeLedger does not operate any analytics, telemetry, logging, or tracking infrastructure. The extension runs entirely inside your browser.

2. Data stored locally (in your browser)

The extension stores the following data only in your browser's local storage and IndexedDB:

  • Your GitHub OAuth access token (used to push commits to your repo)
  • Your AI provider API keys (Gemini, OpenAI, Claude, DeepSeek, Ollama, OpenRouter)
  • Extension settings (repository name, commit preferences, AI configuration)
  • Solved problem metadata and AI reviews (in IndexedDB)
  • AI chat history

None of this data is transmitted to CodeLedger servers. Your browser storage is under your full control.

3. Data sent to GitHub

When you solve a problem, CodeLedger commits the following to your own GitHub repository using the GitHub API:

  • Your solution code
  • Problem metadata (title, difficulty, tags, platform)
  • AI review text (if AI review is enabled)
  • An updated index.json tracking your solved problems

This data goes directly from your browser to GitHub's API. CodeLedger infrastructure is not involved.

4. Data sent to AI providers

If you configure an AI provider, your solution code and problem metadata are sent to that provider using your own API key. Review each provider's privacy policy:

  • Google Gemini
  • OpenAI
  • Anthropic Claude
  • DeepSeek
  • Ollama: runs locally — no external requests

AI review is optional and can be disabled in Settings → AI.

5. The OAuth relay server

CodeLedger operates one server at codeledger.vkrishna04.me/api. Its sole purpose is the GitHub OAuth code exchange:

  • Your browser sends GitHub's temporary code parameter to this server
  • The server exchanges it for an access token via GitHub's API
  • The token is returned to your browser and stored locally
  • The token is never logged, stored, or transmitted elsewhere

The server does not log IP addresses, request bodies, tokens, or any user-identifying information. Cloudflare Workers processes the request in-memory only.

6. The Library web app

The Library at codeledger.vkrishna04.me/library reads your problems directly from your GitHub repository via the GitHub API using your token. No data is cached or stored on our servers.

7. Cookies and tracking

We use no cookies, no third-party analytics (no Google Analytics, Mixpanel, etc.), no fingerprinting, and no advertising SDKs.

8. Children's privacy

CodeLedger is not directed at children under 13. We do not knowingly collect information from children.

9. Changes to this policy

If we make material changes, we will update the "Last updated" date above and note it in the CHANGELOG.
