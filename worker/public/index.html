How it works

Three steps to a complete DSA portfolio

No servers. No databases. No accounts. Just an extension, your API keys, and your GitHub repo.

1

Install the extension

Available on Chrome, Edge, Brave, and Firefox. Connect your GitHub account via OAuth — we only request the repo scope. Your token never leaves your browser.

2

Paste your AI keys

Drop in your own Gemini, OpenAI, Claude, DeepSeek, or Ollama keys in Settings → AI. Keys are stored in your browser's local storage — they never touch our servers.

3

Solve as usual

Hit "Accept" on LeetCode, GFG, or Codeforces. CodeLedger detects the accepted submission, fetches metadata, runs an AI review, and commits everything to your repo in one atomic push.

Features

Everything you need, nothing you don't

Plugin-based architecture — add platforms, AI providers, and git hosts without touching core code.

⚡

Atomic git commits

Uses the GitHub Tree API to commit your code, metadata JSON, and AI review in a single atomic operation. No partial states or multiple noisy commits.

🤖

AI code review

Gemini, OpenAI, Claude, DeepSeek, or local Ollama. Round-robin key pools with automatic fallback if one provider fails. Full chat interface with /mycode slash commands.

Analytics dashboard

Heatmap, topic radar, difficulty donut, solve velocity — all built from your local IndexedDB. Drilldown to individual problems. No telemetry unless you opt in.

Knowledge graph

Problems are linked by topic and algorithmic pattern. Visualize your preparation as an interactive force-directed graph and spot gaps in your coverage.

Adding a new platform or AI provider is a single file. The BasePlatformHandler contract makes contribution straightforward — no core changes needed.

A single codebase, no bundler. A lightweight compat shim handles API differences. Works on Chrome, Edge, Brave, and Firefox from the same source.

Ask anything about a problem directly in the modal — the AI knows your code, the problem statement, constraints, hints, and your past AI review for full context.

FAQ

Common questions

Is CodeLedger free?

Yes, completely. It's open source under Apache 2.0. You bring your own GitHub account and AI API keys — there's no subscription.

Does it upload my code to any server?

No. Your code goes directly from your browser to GitHub's API. The only server we run is the OAuth relay at codeledger.vkrishna04.me/api, which exchanges your GitHub auth code for an access token and immediately forgets it. Your solutions, keys, and personal data never touch our infrastructure.

Which browsers are supported?

Chrome, Edge, Brave, and other Chromium-based browsers via the Chrome Web Store (or unpacked). Firefox via AMO or side-loading. The same extension package supports both — no separate builds needed for core functionality.

Which AI providers are supported?

Gemini (Google), OpenAI (GPT-4o, etc.), Anthropic Claude, DeepSeek, and local Ollama. You can configure a primary and fallback provider, and use your own API keys. No keys are required — you can use CodeLedger without AI review entirely.

Can I use my existing GitHub repository?

Yes. During onboarding you can connect an existing repo. CodeLedger will append new problems without modifying your existing files. It updates a single index.json at the repo root to track solved problems.

What platforms are supported?

Currently LeetCode, GeeksForGeeks, and Codeforces. The plugin architecture makes it straightforward to add new platforms — see ADDING_PLATFORM_HANDLER.md.

How does the AI code review work?

After a successful submission is detected, the service worker sends your code and problem metadata to your configured AI provider. The response is committed alongside your code in the same atomic git commit. You can also open a full chat conversation about any problem from within the extension.

What does the Library web app do?

The Library is the same UI as the extension sidebar, but accessible from any browser at /library. It reads your problems directly from your GitHub repo via the GitHub API — no database, no sync needed.

What is the Behaviour Bank?

The Behaviour Bank is a personal memory layer for the AI assistant. You can store insights ("I always struggle with graph traversal"), define skills that activate on specific commands or difficulty levels, and write a learning roadmap. The AI uses all of these automatically as context in every conversation.

What are MCP tools?

MCP (Model Control Protocol) tools let the AI assistant take actions beyond answering questions — it can save your insight to the Knowledge Bank, recall past solutions, open a specific problem, or update your roadmap, all within the chat panel. You can enable or disable individual tools in Settings → AI.

How does cross-device sync work?

CodeLedger syncs your problem library, AI chat history, and settings through your GitHub repo as structured files. On startup, new problems and chats from other devices are imported automatically. No third-party sync service — just your own repo.

Can I migrate my old problems to the new format?

Yes. The Welcome page (accessible from the extension) has a built-in diagnostic and migration tool. It scans your repo for outdated layout versions and uncommitted problems, then lets you migrate everything with one click.
