# Code of Conduct

## The short version

Be decent to people. This is a tool for tracking solved problems; nothing here is
worth being unpleasant over.

## What that means

- Assume the person on the other end is trying to help
- Criticise the code, not the person who wrote it
- "This is wrong because X" is useful. "This is garbage" is not
- Harassment, personal attacks, and unwelcome attention are not acceptable in
  issues, pull requests, discussions, or anywhere else this project is discussed
- English is a second language for a lot of contributors. Read past the grammar

## If something goes wrong

Email **github@vkrishna04.me**. Reports stay private.

This is a small project maintained by one person, so the range of responses is
narrow: a request to stop, editing or removing a comment, or blocking an account
from the repository. Serious or repeated behaviour gets the last one without a
warning.

## Scope

This applies in the repository, in the issue tracker, and anywhere someone is
representing the project.
