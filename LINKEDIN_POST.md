**Caption:**

Every problem you solve on LeetCode, GeeksForGeeks, or Codeforces is automatically committed to YOUR GitHub repository. Zero clicks. No more invisible grinding.

## What You Get:

⚡ **Zero-Click Commits** — Accepted submissions commit instantly with code + problem statement

🤖 **AI Code Reviews** — Instant complexity analysis and optimization hints (Gemini, OpenAI, Claude, DeepSeek, Ollama, OpenRouter)

📊 **Dashboard** — GitHub-style heatmap, difficulty breakdown, velocity chart, searchable problem table

🕸️ **Knowledge Graph** — Force-directed visualization of everything you've solved, linked by topic

🌍 **Multi-Platform** — LeetCode, GeeksForGeeks, Codeforces work out of the box. Bulk-import your entire history in one click.

💬 **AI Chat Panel** — Ask questions with your code pre-loaded via /mycode

🔒 **100% Yours** — Your data goes to YOUR GitHub repo. No sign-ups, no tracking, no scraping.

## Setup Takes 2 Minutes:
1. Install extension
2. Connect GitHub (OAuth)
3. Set repo name
4. Solve a problem → watch it commit
