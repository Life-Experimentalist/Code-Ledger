# Security Policy

The policy lives in [.github/SECURITY.md](.github/SECURITY.md) — that is the copy
GitHub surfaces in the repository's Security tab and in the "Report a
vulnerability" flow, so it is the one that has to be right.

This file used to be a second, separately maintained policy. The two disagreed
about response times and about what was in scope, and only one of them was ever
shown to anyone. One file now.

**In short:** do not open a public issue. Report privately through
**Security → Report a vulnerability**, or email **github@vkrishna04.me**.
